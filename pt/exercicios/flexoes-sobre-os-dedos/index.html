Flexões sobre os dedos (finger push-ups)

De joelhos, com as mãos apoiadas no chão e os braços esticados, você empurra com os dedos até a palma sair do chão e depois desce devagar. Os braços não dobram: quem trabalha são os dedos e os antebraços.

Na parada de mão, o equilíbrio se corrige com a ponta dos dedos. Quando você começa a cair para a frente, é a pressão deles contra o chão que segura você. Dedos sem força não freiam nada, e cada desequilíbrio termina com um pé no chão. Este exercício fortalece os dedos com só uma parte do seu peso.

Como fazer

  1. De joelhos, apoie as palmas no chão, com os punhos a 90 graus ou mais e os ombros acima das mãos.
  2. Mantenha os dedos no chão e levante a palma empurrando com eles.
  3. Mantenha os cotovelos travados, desça devagar e suba de novo.
  4. Quando ficar fácil, afaste os joelhos das mãos para colocar mais peso sobre as mãos.

Se a palma ainda não sai do chão, comece pelas pulsações sobre os dedos, o mesmo trabalho com menos carga.

Os dois erros a evitar

Dobrar os cotovelos. Os braços acompanham o movimento, a palma sobe graças a eles, e os dedos quase não carregam nada. Mantenha os cotovelos travados: se a palma subir só um centímetro, o exercício já está certo.

Deixar os ombros irem para trás. Para aliviar os dedos, o peso volta para os joelhos e os ombros ficam atrás das mãos. Mantenha os ombros acima das mãos durante todo o movimento, é aí que os dedos trabalham de verdade.

Empurrar com a ponta dos dedos

Sobre a posição das mãos, não defendo uma escola contra outra: depende da morfologia. Só insisto numa coisa, dedos levemente curvados em vez de planos, para poder empurrar com a ponta deles. Este exercício treina exatamente essa pressão, e não pede parede nem material: poucas repetições no fim do aquecimento bastam para melhorar.

Um treinador no ouvido

De cabeça para baixo, não dá para ler uma tela. No app, uma voz guia você durante o exercício e diz o que corrigir na hora em que você precisa. Por exemplo, quando a palma tem dificuldade para sair do chão:

“Empurra forte com os dedos”
